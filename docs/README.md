# Identifier Developer Tools Documentation

Welcome to the documentation for the Universal Identifier Generator & Decoder application.

This suite is crafted to aid engineers in rapidly developing, diagnosing, and asserting different identifier strings directly within a browser environment.

## Table of Contents

1. [Features & Capabilities](./FEATURES.md): An outline of the application capabilities including Generator and Decoder module summaries.
2. [Architecture & Stack](./ARCHITECTURE.md): Technical breakdown of the project patterns, libraries, and codebase structure.

## Quick Start

To run this project locally:
\`\`\`bash

# Install dependencies

npm install

# Start local preview server

npm run dev
\`\`\`
